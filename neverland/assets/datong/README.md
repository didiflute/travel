# Datong miniature assets

The sculpture is an illustrative closed 3D mesh with generated frontal stone imagery, not a scan. The reference for the Cave 20 face is xiquinhosilva's photograph, reproduced by Smarthistory under CC BY 2.0: https://smarthistory.org/wp-content/uploads/2020/11/Buddha-20-scaled.jpg . The generated image extends the reference into a complete frontal seated figure and changes the lighting. The photographic reference is not served by the site. Attribution: xiquinhosilva / Smarthistory; license https://creativecommons.org/licenses/by/2.0/ .

Architectural reference: Hengshan Scenic Area Management Center, https://www.byhs.net.cn/culture_detial/77.html . The site uses original modeled geometry, not that site's photographs. The two landmarks are composed into one memory tile, not shown at their real geographic distance.

The sculpture uses a 640px WebP and a 48 × 88 grid with a closed back. Static rock, building, railing and vegetation geometry is combined by material. The clicked walk only updates three visitors. No extra renderer or reflection target is added for Datong.
