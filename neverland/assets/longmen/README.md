# Longmen miniature assets

These are illustrative assets for a personal travel-memory scene, not a scan or an archaeological reconstruction. Neutral stone imagery was generated with reference to the user's night photograph. The main seated figure and two attendant variants use handmade closed meshes with shaped fronts, backs and perimeter surfaces. Facial and garment details are partly texture-based; side and rear detail is simpler than the front.

The JSON files contain vertex positions, back positions, UV coordinates and triangle indices. The WebP files contain the matching sculpture atlases and a generated limestone texture. The four attendants share two sets of geometry and one atlas. No original high-resolution PNG is needed at runtime.
